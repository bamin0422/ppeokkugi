## 디자인 방향

**배경색과의 조화.** 앱 UI 배경(`#1F1B18–#2A2420`)에서 뻐꾸기의 회청색(`#6B8FA8`)이 살짝 밝게 떠 있어 자연스럽게 인식됩니다. 크림 배(`#F2E8D0`)는 앱의 따뜻한 크림 텍스트 색과 같은 계열입니다.

**정체성.** 머리 위 안테나(끝이 빨간 핀 형태)가 "무전기 기기"임을 직관적으로 표현합니다. 뻐꾸기 시계에서 새가 튀어나오는 동작처럼, 알림이 오면 이 캐릭터가 "뻐꾹!" 하고 등장하는 맥락을 지원합니다.

**표정 시스템.** 눈(노란 고리 크기), 부리(열림/닫힘), 날개 자세, 특수 배지의 네 축으로 표정을 변형합니다. 몸통과 배 줄무늬는 모든 변형에서 고정되어 일관된 캐릭터 아이덴티티를 유지합니다.
