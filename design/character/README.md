# 뻐꾸기 마스코트 캐릭터 (v3)

v3는 실제 뻐꾸기 삽화를 단순화한 옆모습입니다. 단색 면만 쓰고 그라데이션과 외곽선은 쓰지 않습니다. 몸이 가늘고 꼬리가 길어 작게 줄여도 뻐꾸기로 읽힙니다.

이전 판은 보관만 합니다. `v1/`은 부엉이처럼 보인다는 피드백을 받았고, `v2/`(동그란 찹쌀떡 몸)는 뚱뚱해 보인다는 피드백을 받았습니다.

## 파일 목록

모든 캐릭터는 200×200 viewBox이고, 같은 이름의 `.png`는 512px 투명 배경입니다.

| 파일 | 설명 |
|------|------|
| `cuckoo_base` | 기본 옆모습, 횃대에 앉음 |
| `cuckoo_talk` | 벌린 부리 + 웃는 눈 + 소리 물결 (무전 중) |
| `cuckoo_alert` | 뒤로 편 날개 + 큰 눈 + 곤두선 머리 깃 + 느낌표 (급제동 경고) |
| `cuckoo_rest` | 감은 눈 + 숙인 고개 + z (휴게소) |
| `cuckoo_rollcall` | 번쩍 든 날개 + 웃는 눈 + 체크 표시 (점호) |
| `cuckoo_kids` | 0.8배 크기의 새끼, 짧은 꼬리 (키즈 채널) |
| `app_icon_foreground.svg` | 108×108 적응형 아이콘 전경, 옆얼굴과 가슴 줄무늬 (안전 영역 66dp 안) |
| `app_icon_background.svg` | 108×108 적응형 아이콘 배경 |
| `preview.png` | 어두운·밝은 배경 2단, 각 캐릭터 48px 축소본 포함 |

## 디자인 메모

- **뻐꾸기 표시.** 회청색 등, 크림색 배의 가로줄 3개, 노란 눈 테, 긴 꼬리 네 가지입니다. 표정이 바뀌어도 이 네 가지는 고정합니다.
- **자세.** 몸은 세워서 그린 뒤 46도 기울입니다(`gen.py`의 `TILT`). 머리·부리·눈은 기울이지 않아 얼굴이 늘 앞을 봅니다.
- **표정 축.** 눈(점 / 큰 눈 / 웃음 / 감음), 부리(닫힘 / 벌림), 날개(접음 / 듦 / 뒤로 폄), 꼬리 길이, 소품(소리 물결, 느낌표, z, 체크)만 바꿉니다.
- **Android 변환 시.** 경로·원·타원과 `clipPath`만 씁니다. `<text>`와 그라데이션이 없어 VectorDrawable로 옮기기 쉽습니다. 지금 앱은 PNG(`app/src/main/res/drawable-nodpi/`)를 씁니다.
- **다시 만들기.** `tools/gen.py <폴더>`가 SVG를 쓰고, `tools/render.py <폴더>`가 헤드리스 Chrome으로 PNG와 preview를 만듭니다. 캐릭터를 바꾸면 앱 리소스, 서버 정적 파일, `docs/deck/assets/`에도 복사합니다.
