# 뻐꾸기 마스코트 캐릭터 (v7, 2D)

v7은 주황 무전기를 든 플랫 2D 뻐꾸기입니다. 외곽선 없는 연보라(#7B8EF5 계열) 몸, 가로줄이 있는 크림색 배, 큰 흰 눈, 분홍 볼, 주황 부리와 발을 둡니다. 앱 주 색도 이 몸 색에 맞췄습니다.

이전 판은 보관만 합니다. `v6/`는 3D 클레이 질감이 너무 사실적이라는 피드백을 받았고, `v1/`~`v5/`는 그 전 시안입니다.

## 원본

`source/<표정>.png`는 Google Flow 이미지 생성(Nano Banana)으로 만든 1024px 원본입니다. 기본 자세를 8장 뽑아 하나를 고르고, 나머지 표정은 그 그림을 참고 이미지로 붙여 같은 캐릭터로 만들었습니다. 참고한 외부 그림은 없고, 특정 회사의 캐릭터를 따라 그리지 않았습니다.

| `arrive` | 도착 | 주황 깃발을 듦 |

## 파일

| 파일 | 설명 |
|------|------|
| `cuckoo_<표정>.png` | 1024px 투명 PNG. 어른 새는 모두 같은 배율, 새끼는 어른 키의 약 0.62배 |
| `app_icon_background.png` / `app_icon_foreground.png` | 432px 적응형 아이콘. 옅은 연보라(#EEF0FF) 바탕에 기본 자세 새 |
| `preview.png` | 밝은(#F2F4F6)·어두운(#191F28) 바탕 미리보기 |

## 다시 만들기

`python3 tools/cut.py`가 `source/`의 흰 바탕을 걷어 `cuckoo_<표정>.png`와 `preview.png`를 다시 씁니다(Pillow, numpy, scipy 필요). 그림을 바꾸면 앱(`app/src/main/res/drawable-nodpi/cuckoo_<표정>_0.png`, 512px)과 휴대폰 웹(`server/public/cuckoo/<표정>.png`, 512px)에도 줄여서 복사합니다. 덱·소개서·영상은 빌드할 때 이 폴더의 PNG를 가져갑니다.

## 호차 색

호차마다 다른 색 뻐꾸기는 따로 그리지 않습니다. 몸통 픽셀(HSV 색상 205~262°, 채도 0.18 초과, 명도 0.3 초과)의 색상을 고른 색으로 옮기고 채도·명도를 비율로 맞춥니다. 노랑 차(색상 20~60°)는 부리·발·무전기를 다홍(14°)으로 눌러 몸에 묻히지 않게 합니다. 색은 #3182F6·#7B55FF·#14B8D4·#FF3D8B·#FFB331·#F04452·#22B866 일곱 가지이고, 앱은 `ui/Cuckoo.kt`의 `tintedFrame`, 휴대폰 웹은 `phone.html`의 `moodImg`가 같은 규칙으로 칠합니다.
