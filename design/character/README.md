# 뻐꾸기 마스코트 캐릭터 (v6, 3D)

v6는 매끈한 클레이 질감의 3D 뻐꾸기입니다. 회청색 머리·등·날개, 가로줄 세 개가 있는 크림색 배, 짧은 주황 부리, 긴 꼬리, 갈색 눈에 흰 하이라이트를 둡니다. 몸을 날씬하게 잡아 동그랗게 보이지 않게 했습니다.

이전 판은 보관만 합니다. `v1/`은 부엉이처럼 보인다는 피드백을, `v2/`(동그란 찹쌀떡 몸)는 뚱뚱해 보인다는 피드백을, `v3/`(회청색 면으로 칠한 옆모습)는 징그럽다는 피드백을 받았습니다. `v4/`(선화)와 `v5/`(무전기 LCD 픽셀 그림)는 디자인 방향을 바꾸면서 쓰지 않게 됐습니다.

## 원본

`source/<표정>.png`는 Google Flow 이미지 생성(Nano Banana)으로 만든 1024px 원본입니다. 기본 자세를 8장 뽑아 하나를 고르고, 나머지 표정은 그 그림을 참고 이미지로 붙여 같은 캐릭터로 만들었습니다. 참고한 외부 그림은 없고, 특정 회사의 캐릭터를 따라 그리지 않았습니다.

## 표정 9종

| 이름 | 쓰는 곳 | 모습 |
|------|------|------|
| `base` | 기본, 대기, 비 | 서서 웃음 |
| `talk` | 무전 송신 | 주황 무전기를 들고 말함 |
| `rx` | 무전 수신 | 주황 헤드셋을 쓰고 들음 |
| `alert` | 경고, 급제동, 단속 카메라, 대열 이탈, 긴급 콜 | 날개를 펴고 놀람, 빨간 느낌표 |
| `rest` | 휴게소 | 눈을 감고 쉼 |
| `rollcall` | 점호 | 한쪽 날개를 높이 듦 |
| `kids` | 키즈 채널 | 새끼 뻐꾸기 |
| `arrive` | 도착 | 주황 깃발을 듦 |
| `vote` | 휴게소 투표 | 체크 표시 카드를 듦 |

제 그림이 없는 상황은 `StatusViewModel.kt`의 `Mood.fallback`과 휴대폰 웹의 `MOOD_FILE`이 위 그림으로 이어 줍니다.

## 파일

| 파일 | 설명 |
|------|------|
| `cuckoo_<표정>.png` | 1024px 투명 PNG. 어른 새는 모두 같은 배율, 새끼는 어른 키의 약 0.62배 |
| `app_icon_background.png` / `app_icon_foreground.png` | 432px 적응형 아이콘. 옅은 주황 바탕에 기본 자세 새 |
| `preview.png` | 밝은(#F2F4F6)·어두운(#191F28) 바탕 미리보기 |

## 다시 만들기

`python3 tools/cut.py`가 `source/`의 흰 바탕을 걷어 `cuckoo_<표정>.png`와 `preview.png`를 다시 씁니다(Pillow, numpy, scipy 필요). 그림을 바꾸면 앱(`app/src/main/res/drawable-nodpi/cuckoo_<표정>_0.png`, 512px)과 휴대폰 웹(`server/public/cuckoo/<표정>.png`, 512px)에도 줄여서 복사합니다. 덱·소개서·영상은 빌드할 때 이 폴더의 PNG를 가져갑니다.
