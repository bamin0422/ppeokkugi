# 뻐꾸기 마스코트 캐릭터 (v5, 픽셀)

v5는 무전기 LCD 창에 뜨는 32×32 픽셀 뻐꾸기입니다. 짙은 LCD 바탕에 꺼진 칸은 흐린 점으로 남기고, 켜진 칸은 호박색으로 채웁니다. 경고 계열(경고, 급제동, 대열 이탈, 긴급 콜)은 빨간색으로 켭니다. 표정마다 4프레임이고 320ms마다 바뀝니다. 왼쪽 위에는 무전기처럼 신호 막대 4칸이 있고, 무전 송신·수신 때는 막대가 차오르거나 줄어듭니다.

새 모양은 PixelLab(Pro, 1비트 팔레트)이 만든 32×32 후보 64장 가운데 하나를 골라 `tools/gen.py`의 `BIRD`에 옮긴 것입니다. 눈·부리·날개·소품은 그 위에 칸 단위로 직접 그렸습니다.

이전 판은 보관만 합니다. `v1/`은 부엉이처럼 보인다는 피드백을, `v2/`(동그란 찹쌀떡 몸)는 뚱뚱해 보인다는 피드백을, `v3/`(회청색 면으로 칠한 옆모습)는 징그럽다는 피드백을 받았습니다. `v4/`(Google Flow로 만든 선화를 벡터화)는 픽셀 무전기 느낌으로 가기로 하면서 쓰지 않게 됐습니다.

## 팔레트

| 역할 | 색상 |
|------|------|
| LCD 바탕 | `#2A2230` |
| 켜진 칸 | `#FFE9A3` (앱 LCD 글자와 같은 호박색) |
| 경고 계열 켜진 칸 | `#FF6B7F` |
| 꺼진 칸 | 켜진 칸 색, 불투명도 8.6% |

초록은 쓰지 않습니다.

## 파일

| 파일 | 설명 |
|------|------|
| `cuckoo_<표정>.svg` / `.png` | 첫 프레임. 문서·덱이 씀. PNG는 512px |
| `frames/cuckoo_<표정>_<n>.svg` / `.png` | 프레임별 그림. 앱은 PNG(`drawable-nodpi`), 영상은 SVG를 씀 |
| `anim/<표정>.svg` | 프레임을 CSS로 돌리는 움직이는 SVG. 휴대폰 웹(`server/public/cuckoo/`)이 씀 |
| `app_icon_background.png` / `app_icon_foreground.png` | 432px 적응형 아이콘. 전경의 새는 지름 66dp 안전 영역 안에 들어감 |
| `preview.gif` / `preview.png` | 14종 미리보기 |

## 다시 만들기

`python3 tools/gen.py`가 위 파일을 모두 다시 씁니다(Pillow만 필요). 새 모양은 `BIRD`(켜진 칸 `#`)로 정하고, 표정은 `bird()`의 눈·부리·들썩임·젖힘·날개 인자, 신호 막대 `bars()`, 소품 글리프(`EXCL`, `Z`, `CHECK` 등)를 조합해 `ANIMS`에 적습니다. 그림을 바꾸면 앱(`app/src/main/res/drawable-nodpi/cuckoo_*_<n>.png`, 런처 아이콘), `server/public/cuckoo/`, `docs/deck/assets/`에도 복사합니다. 영상은 `docs/video/remotion/scripts/prep.py`가 `frames/`를 복사합니다.
