# 뻐꾸기 마스코트 캐릭터 (v2)

v1(부엉이처럼 보인다는 피드백)은 `v1/`에 보관했습니다. v2는 동그란 찹쌀떡 몸에 얼굴을 아래쪽에 둔 아기 새 스티커 스타일입니다.

|------|------|------|

## 파일 목록

모든 캐릭터는 200×200 viewBox이고, 같은 이름의 `.png`는 512px 투명 배경입니다.

| 파일 | 설명 |
|------|------|
| `cuckoo_base` | 기본 정면 |
| `cuckoo_talk` | 웃는 눈 + 벌린 부리 + 소리 물결 (무전 중) |
| `cuckoo_alert` | `> <` 눈 + 땀방울 + `!` 말풍선, 날개 들썩 (급제동 경고) |
| `cuckoo_rest` | 졸린 눈 + 처진 안테나 + 김 나는 컵 + zz (휴게소) |
| `cuckoo_rollcall` | 한쪽 날개 번쩍 + `^ ^` 웃음 + 반짝이 (점호) |
| `cuckoo_kids` | 더 작고 둥근 아기, 머리에 알껍데기 (키즈 채널) |
| `app_icon_foreground.svg` | 108×108 적응형 아이콘 전경, 얼굴 클로즈업 (안전 영역 66dp 안) |
| `app_icon_background.svg` | 108×108 적응형 아이콘 배경, 크림 |
| `preview.png` | 어두운(`#1f1b18`)·밝은 배경 2단, 각 캐릭터 48px 축소본 포함 |

## 디자인 메모

- **귀여움 규칙.** 머리와 몸을 한 덩어리로, 눈은 작고 넓게, 얼굴은 몸 중간보다 아래. 노란 눈 테두리와 목은 쓰지 않습니다 (v1이 부엉이로 보인 원인).
- **정체성.** 배의 짧은 줄 3개가 뻐꾸기, 머리 위 꼬불 새싹 + 하트가 무전기 안테나입니다. 표정이 바뀌어도 몸, 배, 줄무늬는 고정합니다.
- **표정 축.** 눈(점 / `^ ^` / `u u` / `> <`), 부리(닫힘 / 벌림), 날개 자세, 소품(소리 물결, 땀방울, 컵, 반짝이)만 바꿉니다.
- **Android 변환 시.** `cuckoo_rest`의 `z`는 `<text>`라서 VectorDrawable로 옮길 때 경로로 바꿔야 합니다. 나머지는 경로와 그라데이션만 씁니다.
- **다시 만들기.** `tools/gen.py <폴더>`가 SVG를 쓰고, `tools/render.py <폴더>`가 헤드리스 Chrome으로 PNG와 preview를 만듭니다.
