# 뻐꾸기: 차가 먼저 말하는 단체 무전

현대자동차그룹 Pleos 앱 대회 출품작 구현 계획서 (2026-10-31 작성)

## 1. 이름과 한 줄 소개

**뻐꾸기**는 여러 대가 함께 움직일 때 쓰는 차량용 단체 무전 앱입니다. 뻐꾸기시계가 때맞춰 "뻐꾹" 하고 알리듯, 차가 필요한 순간에 일행에게 소식을 알린다는 뜻으로 이름을 지었습니다. 영문 표기는 Cuckoo입니다.

> 휴대폰 무전은 사람이 말하고, 뻐꾸기는 차가 말합니다.

기존 휴대폰 무전 앱(Koast, Roger That, Convoy Tracker)은 사람이 버튼을 눌러야 소식이 전해지지만 뻐꾸기는 브레이크, 와이퍼, 방향지시등, 좌석 착석, 에어백 같은 차량 신호를 읽어 일행에게 먼저 알립니다. 좌석마다 스피커와 마이크를 나누어 쓰는 기능도 Pleos 차량에서만 가능합니다.

## 2. 쓰는 상황

| 상황 | 규모 | 핵심 요구 |
|---|---|---|
| 명절 귀성길 친척 차량 | 2~4대 | 휴게소 맞추기, 아이들끼리 무전 |
| 캠핑·차박 동호회 | 5~15대 | 대열 유지, 놓친 차 합류 |
| 결혼식·장례 운구 행렬 | 3~10대 | 앞차를 놓치지 않는 안내 |
| 회사 워크숍·교회 수련회 | 5~20대 | 출발 점호, 인원 파악 |
| 제주 렌터카 가족 여행 | 2~3대 | 동시 이동, 주차장 합류 |
| 자동차 동호회 투어링 | 10대 이상 | 선두 공지, 주행 기록 |

## 3. 기능 구성

무전에서 쓰는 말투로 기능 이름을 붙였습니다. 우선순위는 P0(대회 시연 필수), P1(제출 전 가능하면 포함), P2(제출 이후)로 나눕니다.

| 기능 | 하는 일 | 쓰는 신호 | 우선순위 |
|---|---|---|---|
| 자동 콜 | 급제동·비·회전·제한속도 변경·주의 구간을 차가 스스로 알림 | Brake, Wiper, TurnSignal, 내비 안내 | P0 |
| 받아 적기 | 말을 글로 받아 적고 짧게 줄여 음성으로 전달, 누가 말했는지 표시 | STT, 화자 식별, TTS | P0 |
| 좌석 채널 | 운전석·조수석·뒷좌석 채널을 나누어 해당 좌석 스피커로만 출력 | TTS 오디오 존, Seat | P0 |
| 쉬어 가 | 일행 중 주행가능거리가 가장 짧은 차를 기준으로 휴게소 후보를 내고 투표, 결과를 모든 차에 경유지로 등록 | Odometer, Fuel, EvBattery, NaviHelper | P0 |
| 다시 붙기 | 대열에서 떨어진 차에 선두 경로를 경유지로 넣어 합류 | FusedLocation, NaviHelper | P0 |
| 점호 | 출발할 때 차마다 탑승 인원과 안전벨트 상태를 모아 알림 | Seat 착석, Safety 안전벨트 | P0 |
| 대장 콜 | 선두가 경로를 바꾸면 모든 차가 함께 다시 탐색 | NaviHelper | P1 |
| 꼬리 콜 | 후미가 2km 이상 떨어지면 선두에 감속 안내 | FusedLocation | P1 |
| 긴급 콜 | 어느 차든 에어백이 전개되면 위치와 함께 전원에게 알림 | Safety 에어백 | P1 |
| 깃발 색 | 차마다 고유 색을 정해 앰비언트 조명에 표시하고, 주차장에서 서로를 찾을 때 깜빡임 | Light 앰비언트 | P1 |
| 휴대폰 참여 | Pleos 차량이 아닌 일행도 휴대폰 웹으로 위치와 무전에 참여 | 휴대폰 GPS | P1 |
| 무전 일지 | 대열 경로와 무전 기록을 여행 앨범으로 정리 | 전체 기록 | P2 |
| 길 위 채널 | 같은 정체 구간에 있는 모르는 차들끼리 잠시 열리는 공개 채널 | 내비 정체 정보 | P2 |

## 4. 시스템 구조

```
[Pleos 차량 앱] ─┐
[Pleos 차량 앱] ─┼─ WebSocket ─ [Cloudflare Worker + Durable Object: 방 1개 = 일행 1팀]
[휴대폰 웹]   ─┘                         └─ [가상 차량 봇: 시연용]
```

### 4.1 차량 앱

- 언어와 화면: Kotlin, Jetpack Compose, Android Automotive(compileSdk 35, minSdk 28)
- Pleos SDK: `Vehicle:2.3.2`, `NaviHelper:3.0.5`, `FusedLocation:1.1.3`, `TextToSpeech:3.3.1`, `SpeechToText:3.3.1`. 필요하면 `LLM:2.1.3.2`(ON_DEVICE 모드만 사용)를 추가합니다.
- 패키지: `com.ppeokkugi`
- 구성

| 폴더 | 역할 | 출처 |
|---|---|---|
| `car/` | 차량·내비·위치 신호를 `CarEvent`로 바꾸는 연결부와 데모 주행 | 길품 `CarBridge.kt`, `Navi.kt`, `Locator.kt`, `Demo.kt`를 옮겨 고침 |
| `voice/` | STT 받아 적기, 화자 식별, 좌석별 TTS 출력 | 길품 `Voice.kt`를 확장 |
| `net/` | 방 접속과 메시지 송수신(OkHttp WebSocket), 끊기면 자동 재접속 | 새로 작성 |
| `domain/` | 급제동·이탈·휴게소 판정 규칙, 투표 집계 | 새로 작성 |
| `ui/` | 운전자 화면(최근 무전 3개와 일행 지도), 승객 화면(채널, 투표) | 길품 테마와 지도 컴포넌트를 재사용 |

길품 프로젝트(`~/orca/projects/imjang-drive`)는 보관 상태로 두고 파일을 복사해서 씁니다.

### 4.2 서버

- 방 코드 하나가 `Room` 인스턴스 하나에 대응하도록 Cloudflare Worker 하나에 Durable Object 클래스 `Room`을 둡니다.
- WebSocket Hibernation API를 써서 무전이 없는 동안의 실행 비용을 줄입니다.
- 방은 마지막 활동 후 24시간이 지나면 저장 상태와 함께 삭제합니다.
- 음성 원본은 서버로 보내지 않고 받아 적은 글만 전달하며 받는 차가 TTS로 읽습니다. 이렇게 하면 전송량이 줄고 좌석별 출력이 쉬워집니다.
- 로컬 개발은 `wrangler dev`로 하고 에뮬레이터는 `http://10.0.2.2:<포트>`로 접속합니다. 길품 서버가 8791 포트를 쓰므로 뻐꾸기는 8792 포트에 띄웁니다.
- 실제 배포(`wrangler deploy`)는 사용자 확인을 받은 뒤에 진행합니다.

### 4.3 가상 차량 봇

시연에는 에뮬레이터 한 대만 쓸 수 있으므로 나머지 일행은 `server/scripts/bots.mjs`가 대신합니다. 봇은 정해진 경로(경부고속도로 서울 요금소부터 안성 휴게소까지)를 따라 위치를 보내고 정해진 시각에 급제동·와이퍼·발화 이벤트를 냅니다.

## 5. 메시지 형식

모든 메시지는 JSON이며 `type` 필드로 구분합니다.

| type | 보내는 쪽 | 내용 |
|---|---|---|
| `hello` | 차량 | 차 번호(1호차, 2호차), 별칭, 깃발 색, 좌석 구성 |
| `pos` | 차량 | 위도, 경도, 방향, 속도(km/h), 시각. 2초마다 전송 |
| `signal` | 차량 | `brake_hard`, `rain`, `turn_left`, `turn_right`, `speed_limit`, `caution`, `caution`, `airbag` 중 하나와 위치 |
| `say` | 차량 | 보낸 차, 좌석, 화자, 채널(`all`, `adult`, `kids`), 글 |
| `roll` | 차량 | 좌석별 착석 여부와 안전벨트 착용 여부 |
| `route` | 선두 | 경유지 목록과 목적지 |
| `vote_open` / `vote` / `vote_result` | 서버·차량 | 휴게소 후보, 각 좌석의 선택, 최종 결과 |
| `rejoin` | 서버 | 대열에서 떨어진 차에 보내는 합류 경로 |

## 6. 기능별 판정 규칙

### 6.1 자동 콜

- **급제동**: 브레이크가 눌린 상태에서 2초 안에 속도가 15km/h 이상 떨어지면 `brake_hard`를 보냅니다. Pleos `Brake`는 페달을 밟았는지만 알려 주므로 속도는 연속한 위치 값으로 계산합니다. 같은 차에서는 20초 안에 다시 보내지 않습니다.
- **비**: 와이퍼가 꺼짐에서 켜짐으로 바뀌는 순간에 한 번 보내고 10분 동안은 다시 보내지 않습니다. 받는 차에는 "5km 앞부터 비"처럼 보낸 차와의 거리를 붙여 읽습니다.
- **회전**: 선두 차량의 방향지시등만 사용하되 내비 안내(`getTBTInfo`)에서 500m 안에 같은 방향 회전이 있을 때만 "선두, 300m 앞 우회전"을 보냅니다. 차선 변경으로 켠 방향지시등은 이 조건으로 걸러집니다.
- **제한속도 변경과 주의 구간**: 선두가 받은 `onCurrentRoadSpeedLimit` 값이 바뀌거나 `onCautionPointInfo`(어린이보호구역 등)가 오면 뒤따르는 차에 "선두, 제한속도 50으로 바뀜"처럼 전달합니다. 단속 카메라 위치는 일행에게 공유하지 않습니다. 선행 사례 조사에서 단체 주행 앱의 카메라 공유가 단속 회피 도구로 읽힐 위험이 확인됐기 때문입니다.
- 급제동 알림은 서버를 거치므로 1초 안팎의 지연이 생길 수 있습니다. 화면과 음성에 "안전장치가 아니라 미리 알려 드리는 안내"라고 밝힙니다.

### 6.2 받아 적기

1. 승객 화면의 큰 무전 버튼을 누르거나 호출어 "무전"을 말하면 STT를 시작합니다. 운전자는 호출어만 사용합니다.
2. STT 화자 식별 결과(`Speaker.getSpeakerId()`)를 좌석과 이름에 대응시켜 "2호차 할머니"처럼 표시합니다. 화자 식별이 좌석을 알려 주지 않으면 출발할 때 한 번씩 이름을 말하게 해서 목소리를 등록합니다.
3. 40자를 넘는 글은 온디바이스 LLM으로 한 문장으로 줄입니다. LLM을 쓸 수 없으면 첫 문장만 보냅니다.
4. 받는 차는 운전자 채널에 짧은 글만 읽고 원문은 승객 화면에 남깁니다.

### 6.3 좌석 채널

- 좌석(`SeatArea`)마다 오디오 존 번호를 정하고 TTS를 출력하기 전에 `setAudioZoneId`를 호출합니다.
- 기본 배치는 운전석 = 안내만, 조수석 = 어른 채널, 뒷좌석 = 키즈 채널이며 승객 화면에서 바꿀 수 있습니다.
- 키즈 채널에서는 차와 차 사이의 끝말잇기, 퀴즈 같은 놀이를 제공합니다(P1).
- 오디오 존이 좌석별로 나뉘지 않으면 모든 소리를 한 스피커로 내보내고 앞에 "키즈 채널"처럼 채널 이름을 붙여 구분합니다.

### 6.4 쉬어 가

- 다음 중 하나가 생기면 투표를 엽니다.
  - 일행 중 가장 짧은 주행가능거리가 남은 경로 거리에 30km를 더한 값보다 짧은 경우
  - 마지막 휴식 뒤 2시간이 지난 경우
  - 누군가 "화장실", "쉬었다 가자"를 말한 경우
- 후보는 경로 앞쪽 휴게소 2~3곳입니다. Pleos 내비는 휴게소 목록을 주지 않으므로 시연에서는 해당 고속도로 구간의 휴게소 좌표를 담은 JSON을 앱에 넣습니다. 실서비스에서는 한국도로공사 공공데이터의 휴게소 위치 자료를 씁니다(사용 조건은 아직 확인하지 않았습니다).
- 좌석마다 "1번", "2번"을 말해 투표합니다. 30초가 지나거나 모두 투표하면 결과를 정하고 동점일 때는 선두가 정합니다.
- 결과는 모든 차의 내비에 `addWaypoint`로 등록합니다.
- 결과 안내에는 점호 결과에서 가져온 일행 전체 인원을 붙입니다(예: "안성 휴게소, 총 11명").

### 6.5 다시 붙기

- 선두가 지나간 경로에서 300m 넘게 벗어난 상태가 30초 이어지거나, 선두와의 거리가 5km를 넘으면 대열 이탈로 판정합니다.
- 서버가 선두의 다음 회전 지점을 `rejoin`으로 보내면 차량 앱이 그 지점을 경유지로 넣고 "선두를 따라가는 경로로 바꿨습니다"라고 안내합니다.

### 6.6 점호

- 기어가 처음 D로 바뀌면 좌석별 착석과 안전벨트 상태를 `roll`로 보냅니다.
- 선두는 "1호차 4명 벨트 완료, 2호차 뒷좌석 왼쪽 벨트 미착용"처럼 모아서 듣습니다.

### 6.7 P1 기능

- **대장 콜**: 선두의 경로 변경을 `route`로 보내고 다른 차는 `requestRouteWithWaypoints`로 다시 탐색합니다.
- **꼬리 콜**: 서버가 위치로 후미와 선두의 거리를 계산하고 2km를 넘으면 선두에 "후미 2km 뒤, 천천히"를 보냅니다. 5분 동안은 같은 안내를 다시 보내지 않습니다.
- **긴급 콜**: 모든 좌석에 `registerSeatAirbagDeployed`를 등록합니다. 전개 신호가 오면 위치와 함께 `airbag`을 보내고 받는 차는 소리와 전체 화면으로 알립니다. 시연에서는 디버그 메뉴로 이 신호를 주입합니다.
- **깃발 색**: 방에 들어올 때 차마다 색을 받아 앰비언트 조명을 바꿉니다. 일행 차량이 150m 안에서 모두 기어 P 상태가 되면 조명 밝기를 세 번 깜빡여 도착을 알립니다.

## 7. 운전 안전과 개인정보

- 플랫폼의 `CarUxRestrictions`를 따라 주행 중에는 운전자 화면에서 글자 입력과 목록 스크롤을 막고 음성과 큰 버튼만 남깁니다.
- 위치는 방에 들어와 있는 동안에만 공유하고 방이 삭제되면 위치 기록도 함께 지웁니다.
- 음성 원본은 차 밖으로 내보내지 않습니다.
- 휴대폰 웹 참여자에게는 위치 공유 동의를 먼저 받습니다.

## 8. 에뮬레이터 검증 항목

Pleos Connect Emulator 2.1.0에서 길품을 개발할 때 확인한 항목과 아직 확인하지 않은 항목을 나눕니다. 신호는 Virtual Console(`adb forward tcp:8088 tcp:8088` 후 `http://127.0.0.1:8088/`)로 주입합니다.

| 항목 | API | 상태 | 확인되지 않을 때의 대안 |
|---|---|---|---|
| 브레이크 페달 | `Brake.registerBrakePedalStatus` | 데모 주행으로 확인 | 해당 없음 |
| 와이퍼 | `Wiper.registerWiperState` | 확인 | 해당 없음 |
| 방향지시등 | `TurnSignal.registerTurnSignalState` | 확인 | 해당 없음 |
