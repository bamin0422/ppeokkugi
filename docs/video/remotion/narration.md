# 소개 영상 나레이션 대본 (일레븐랩스)

가로 소개 영상(`wide`)은 n05, n07~n12, n16, n17 아홉 줄만 쓴다(로고 → 연락 → 정보 공유 → 도착 확인 → 운행 보고서 → 맺음). 나머지 줄은 예전 컷과 숏폼(`short`) 목록에 남아 있는 것이다. 장면 id는 `src/scenes.json`과 맞춘다. 한 줄 = 음성 파일 하나(`public/audio/vo/<id>.mp3`). 생성한 원본은 `vo_orig/`에 두고, 영상에는 음높이를 그대로 둔 채 10% 빠르게 하고(ffmpeg `atempo=1.10`) 음량을 8dB 낮춘 파일을 쓴다(앱 음성 안내와 크기를 맞추기 위해). 목소리는 ElevenLabs "Jisoo"(Eleven v4)이고, 감정 태그 없이 아래 문장을 그대로 넣어 또렷한 안내 톤으로 만들었다.

| id | 장면 | 나레이션 |
|---|---|---|
| n01 | convoy (연출 이미지: depart, convoy_dusk) | 명절 귀성길, 친척 네 집이 차 네 대로 함께 출발합니다. |
| n02 | pain (연출 이미지: traffic_gap) | 하지만 대열은 금세 흩어지고, 운전 중에는 전화도 문자도 하기 어렵습니다. |
| n03 | purpose | 운전 중에도 일행 전체와 끊기지 않는 연락이 필요합니다. |
| n04 | clock | 뻐꾸기시계가 때맞춰 알려 주듯, 필요한 순간에 일행에게 소식을 전합니다. |
| n05 | logo (가로) | 차량용 단체 무전, 뻐꾸기입니다. |
| n06 | concept (연출 이미지: ptt_press, cockpit) | 버튼 한 번 누르고 말하면, 일행의 모든 차가 동시에 듣습니다. 말이 없을 때는 차가 대신 무전합니다. |
| n07 | f:tx (가로, 연락) | 무전 버튼을 누르고 말하면, 모든 차량에 바로 전달됩니다. |
| n08 | f:rx (가로, 연락) | 다른 차의 무전은 화면을 보지 않아도 스피커로 들립니다. |
| n09 | f:brake (가로, 정보 공유. 숏폼은 연출 이미지 brake_chain 위) | 앞차가 급제동하면, 거리까지 계산해 뒤따르는 차에 자동으로 알립니다. |
| n10 | f:vote (가로, 정보 공유) | 쉬어 갈 휴게소는 투표로 정합니다. 번호만 말하면 됩니다. |
| n11 | f:waypoint (가로, 정보 공유) | 결과는 모든 차의 내비게이션에 경유지로 들어갑니다. |
| n12 | f:arrive (가로, 도착 확인) | 도착하면 자동으로 알리고, 모두 모이면 함께 알려 줍니다. |
| n13 | sdk | 차량 신호와 순정 내비, 스피커와 마이크, 차량 위치. Pleos 차량이라서 가능한 무전입니다. |
| n14 | usecase (연출 이미지: kids_backseat, bus_convoy) | 가족 귀성길부터 수학여행 단체 버스까지. |
| n15 | fleet (연출 이미지: dispatcher, bus_driver) | 운수사 관제실은 운행 중인 기사 모두에게 한 번에 공지하고, |
| n16 | report (가로, 운행 보고서) | 운행이 끝나면 차량별 보고서가 남습니다. |
| n17 | outro (가로는 로고만) | 운전 중에도 일행 전체와 끊기지 않는 연락. 뻐꾸기. |

가로 영상의 `f:tail`(일행 위치·처짐 알림) 장면은 나레이션 없이 자막만 쓴다.
