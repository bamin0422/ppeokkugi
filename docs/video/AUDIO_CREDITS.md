# 소리 출처

뻐꾸기 소개 영상(`뻐꾸기_소개영상.mp4`)과 숏폼(`뻐꾸기_숏폼.mp4`)에 들어간 소리는 아래가 전부입니다. 외부 음원·샘플·효과음 라이브러리는 쓰지 않았습니다.

| 소리 | 출처 | 만든 방법 |
|---|---|---|
| 배경음악 (로파이 팝, 96 BPM) | 직접 작곡 | `remotion/scripts/prep.py`의 `bgm()`이 numpy로 합성. FM 전자 피아노 화음(Cmaj7–Am7–Dm7–G7sus), 사인파 베이스, 사인 킥·잡음 스네어·셰이커, 종소리 선율. 피아노만 나오는 인트로 2마디, 본곡 반복, 끝 화음으로 구성하고 길이를 영상에 맞춤 |
| 무전 딸깍·스켈치 (`ptt`) | 직접 합성 | 사인파 딸깍과 짧게 감쇠하는 대역 통과 잡음 |
| 로저 비프 (`roger`) | 직접 합성 | 1175Hz·1568Hz 사인 두 음과 짧은 스켈치 꼬리 |
| 휙 (`whoosh`) | 직접 합성 | 대역이 올라가는 잡음, 고역을 깎아 부드럽게 |
| 톡 (`blip`, 자막 등장) | 직접 합성 | 음높이가 내려가는 짧은 사인파 |
| 급제동 경보 (`alert`) | 직접 합성 | 1046Hz·1397Hz 사인 두 음 번갈아 3회 |
| 뻐꾹 (`cuckoo`) | 직접 합성 | 784Hz → 622Hz로 내려가는 두 음(장3도), 사인파와 배음 |
| 앱 음성 안내 | 뻐꾸기 앱 실제 출력 | Pleos Connect Emulator 녹화(`src/raw`)에 함께 담긴 앱의 Pleos TextToSpeech 출력. 18dB 올림 |

내레이션(합성 음성)은 넣지 않았습니다.
